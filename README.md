## 项目说明

FRE123 后台管理系统
本仓库是 FRE123 导航管理后台「导航管理」模块的代码整理（我负责的部分）。

原始项目：https://github.com/fre123-com/fre123-nav

贡献者名单（含我）：https://github.com/fre123-com/fre123-nav

## 环境要求

- node: v18.16.0
- yarn: 1.22.19

## 二、安装步骤

- clone

```sh
cd fre123_nav_admin
```

- install

```sh
yarn install
```

- run

```sh
yarn dev
```
