## 项目说明

FRE123 后台管理系统
本仓库是 FRE123 导航管理后台「导航管理」模块的代码整理（我负责的部分在其中）。

独立完成后台fre123_nav_admin/src/views/nav_category 和/view/nav_site两个模块（包含部分routers实现）：

实现导航条目增删改查、多级分类管理、拖拽排序与实时保存、批量导入/导出。

原始项目：https://github.com/fre123-com/fre123-nav

贡献者名单（含我）：https://github.com/fre123-com/fre123-nav

## 环境要求

- node: v18.16.0
- yarn: 1.22.19

## 二、安装步骤

- clone

```sh
cd fre123_nav_admin
```

- install

```sh
yarn install
```

- run

```sh
yarn dev
```
